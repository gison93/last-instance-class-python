While I was reading "The Road" by Cormac McCarthy a paragraph grabbed my attention.

```
The fraility of everything revealed at last.
Old and troubling issues resolved into nothingness and night.
The last instance of a thing takes the class with it.
Turns out the light and is gone.
Look around you.
Ever is a long time.
But the boy knew what he knew.
That ever is no time at all.
```

It's pretty poetic, but I am sure if you are here you noticed a specific sentence:

_The last instance of a thing takes the class with it._

The moment after I read it I thougt: "Is it possible to build in Python a class that satisfy this requirement?"
